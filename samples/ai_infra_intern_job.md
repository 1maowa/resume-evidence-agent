# AI Infra 实习生

## 实习职责

参与密态推理系统研发，将计算引擎与主流大模型推理框架（如 vLLM 等）深度集成与优化，参与大模型推理 Pipeline 设计与实现。

分析和优化 GPU 上的计算执行效率，包括 Kernel 融合、显存管理、通信优化等，使用 profiling 工具定位瓶颈。

在多节点 GPU 集群上进行模型并行、流水线并行部署，处理模型切分、数据流调度、节点间高效通信等问题。

协助搭建云原生环境下的自动化部署、监控和弹性伸缩体系，保障线上服务稳定性和高可用性。

跟进 AI Infra 和系统安全领域最新研究成果，探索新技术在计算平台的应用。

## 任职要求

1. 国内外名校计算机、人工智能、数学等相关专业本科、硕士或博士在读。
2. 熟练掌握 Python、CUDA 等，具备一定 AI Infra 知识经验。
3. 对人工智能、大模型、计算机体系结构、操作系统等有一定理解。
4. 一周能保证至少 4 天线下工作时间。

## 加分项

1. 有 vLLM、PyTorch 等框架源码贡献经验。
2. 在系统方向 CCF-A 类会议发表过第一作者论文。
3. 在 ICPC/CCPC 等赛事获得银牌及以上奖励。
4. 有生产级 LLM serving、MaaS、GPU 云或 AI Infra 经验。
5. 熟悉 vLLM、SGLang、TensorRT-LLM、Dynamo、Triton 中任一技术栈。
6. 熟悉 Kubernetes、Prometheus/Grafana、OpenTelemetry 或服务网格。
7. 做过大模型 API 网关、流量调度、CDN/RTC、数据库、搜索推荐、消息队列等性能敏感系统。
8. 设计过大模型 API 多租户资源调度、配额、容量或成本治理系统。
9. 有 AI Agent 在线负载的大模型 API 服务与优化经验。
10. 在 OSDI、SOSP、PPoPP、HPCA、SC、ASPLOS、ISCA、ATC、EuroSys 等 CCF-A 类会议上以第一作者发表过论文。
11. 在超算、ICPC、CCPC 等比赛中获得佳绩。
